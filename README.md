# 副业收集工作台

一个纯静态 PWA，帮你挖掘、筛选、测算和跟踪副业方向。在线使用：https://xiaomin999.github.io/side-hustle-hub/

## 功能

- **点子库**：86 条副业方向，覆盖电商卖货、内容创作、技能接单、知识付费、数字产品、本地生活、AI 应用、信息差 8 大类。按启动资金、每天时间、技能门槛、风险等级、类别、关键词实时筛选。
- **AI 挖掘**：本地组合引擎（变现模式 × 流量渠道 × 能力资产）生成候选方向，附 7 天冷启动动作；提示词工坊可生成结构化 prompt 交给 AI，返回的 JSON 可导入点子库。
- **收益测算**：卖货 / 服务两种模式，算月净利、毛利率、回本周期、时薪，支持多方案横向对比。
- **我的副业**：5 种状态（待调研 / 测试中 / 已启动 / 已盈利 / 已放弃）跟踪，记录笔记、下一步行动与真实投入产出。

## 技术

无框架、无构建、无后端。HTML + CSS + 原生 JS，数据存 localStorage（key `shh.v1`），Service Worker 支持离线访问与安装到桌面。

## 本地运行

```bash
python -m http.server 8080
# 打开 http://127.0.0.1:8080
```

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面骨架 |
| `data.js` | 86 条副业数据集 + 分类定义 |
| `app.js` | 筛选、挖掘、测算、跟踪的全部逻辑 |
| `style.css` | 样式（含移动端底部导航） |
| `manifest.json` / `sw.js` | PWA 配置与离线缓存 |
| `icons/` | 192 / 512 应用图标 |
